def test_an_unknown_tool_and_a_crashing_tool_are_results_too(caplog):
    def crash(tool_input):
        raise KeyError("a bug in our tool")

    broken = Tool("broken", "Always fails.", {"type": "object"}, crash)
    run = run_agent(MockClient(), ask("[mock:call broken {}]"), [broken], 5)
    assert run.messages[2]["content"][0]["content"] == "The tool failed unexpectedly."
    assert "tool broken crashed" in caplog.text  # the details are in our log only

    run = run_agent(MockClient(), ask("[mock:call delete_everything {}]"), [broken], 5)
    assert run.messages[2]["content"][0]["content"] == "There is no tool named 'delete_everything'."

6Agent או workflow?

החלופה, על ענף זמני:

agent\conversations.py (the workflow version, not kept)
    def answer(self, conversation_id: str, prompt: list[MessageParam]) -> str:
        """Always fetch the notes, put them before the question, and make one call."""
        if self.notes is None:
            return self.client.reply(prompt)
        try:
            found = self.notes.list(conversation_id)
        except NotesUnavailable:
            found = []  # answer without them
        context = "Notes saved in this conversation:\n" + "\n".join(f"- {n.text}" for n in found)
        question = prompt[-1]["content"]
        with_notes: MessageParam = {"role": "user", "content": f"{context}\n\n{question}"}
        return self.client.reply(prompt[:-1] + [with_notes])

(ruff יבקש למחוק את ה-import של run_agent ו-notes_tool, שכבר לא בשימוש, ולהוסיף את NotesUnavailable.) המדידה: Conversations.send() על הודעה אחת, בשיחה חדשה, עם שלוש הערות בשירות מזויף (כמו ב-test_loop.py), פעם על הענף הזמני ופעם על main:

ה-workflow זול בהרבה בכל הודעה, כי הגדרת הכלי לא נשלחת ואין צעד שני. מה שמכריע לכיוון השני הוא השורה של notes calls: ה-workflow קורא לשירות ההערות בכל הודעה, וכשהשירות למטה, כל "hello" מחכה כשש שניות. וכשיש מאות הערות, כולן נכנסות לכל פרומפט. ההחלטה בפרויקט, ב-docs\adr\0002-notes-reach-the-model-through-a-tool.md: הלולאה, עם הנימוקים, המספרים, וההשלכות (כולל העלות). מה היה הופך אותה: אם רוב ההודעות היו על הערות, או אם היו רק כמה הערות קצרות ושירות מהיר. זו לא החלטה "נכונה" אחת; זו החלטה שכתובה עם הסיבות שלה, כדי שאפשר יהיה לשנות אותה כשהמספרים ישתנו.
