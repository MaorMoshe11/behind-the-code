# Starter files

The three files chapter 1 begins with. The chapter tells you when to copy them into your
own project folder (`~\projects\my-agent`); do not work on them here.

| File | What it is |
|---|---|
| `chat.py` | A small chat with Claude in the terminal. It also runs without an API key, in mock mode |
| `debug_me.py` | A short program with one planted bug, for the debugger exercise |
| `.env.example` | The settings the chat reads, as a template for your own `.env` |
